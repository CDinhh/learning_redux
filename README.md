# Learning Redux - Todo App

A project to learn Redux by building a Todo App with React + Redux Toolkit.

## Description

A simple Todo application with full features:
- Add, delete, and mark todos as completed
- Filter by status (All, Completed, Todo)
- Search by name
- Filter by priority (High, Medium, Low)
- State management with Redux Toolkit

## Technologies

- React
- Redux Toolkit
- Ant Design
- UUID

## Installation

```bash
npm install
```

## Run the application

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app in the browser.
